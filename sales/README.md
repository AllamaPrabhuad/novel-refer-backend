# Sales materials

| File | What it is |
| --- | --- |
| `novel-tissues-pitch-deck.pdf` | 10-slide deck for buyer meetings (16:9) |
| `rollup-banner-85x200cm.pdf` | Trade show roll-up banner with a QR code to /expo/ |
| `qr-expo.svg` | The QR code on its own, for stickers, visiting cards and stands |
| `outreach-templates.md` | Cold emails, follow-ups, LinkedIn and WhatsApp messages |
| `marketplace-listings.md` | IndiaMART, TradeIndia and Alibaba copy |
| `content-calendar.md` | 12 months of blog topics |
| `launch-checklist.md` | Everything left to switch on before and after launch |

Product spec sheets (one per category) are on the website in `public/b2b/downloads/`.

The PDFs are generated from the same content as the website. After changing products, contact details or the domain, run:

```bash
npm run build:assets
```
